# RESLibrariesNet10

Proyecto **host** de la solución y **documentación central** de RESLibrariesNet10.

Librerías genéricas **.NET 10** (C#), reutilizables en distintos proyectos.

| Campo | Valor |
|-------|--------|
| **GitHub** | https://github.com/respada-pgr/RESLibrariesNet10 |
| **Rama** | `dev` |
